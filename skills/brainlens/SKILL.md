# BrainLens Neurophysiology Workbench Skill

Use the `brainlens` MCP server (or `brainlens` CLI) to assist epileptologists, neurophysiology fellows, and EEG/ML researchers in presurgical HFO screening, signal QC, visual verification, and sensitivity analysis.

## 1. The 7 Orthogonal Tools

1. `inspect_case(target="*", modality=None, spatial_sidecar=None, anatomy_sidecar=None, anatomy_source=None, anatomy_patient_native=False)`
   - Pass `target="*"` to list registered cases, local `inputs/`, saved protocols, and PyHFO/ONNX engine health.
   - Pass a file, folder, BIDS directory, or case name (`"HUP134"`, `"inputs/synthetic_seeg.edf"`, `"inputs/ZurichHFO"`) to inspect shafts, physical units, sampling rate, reference, 3D coordinates, and per-recording provenance.
   - For a registered case, `anatomy_sidecar` imports an external contact/region CSV/TSV (or BIDS `*_electrodes.tsv`) — always supply `anatomy_source`, and set `anatomy_patient_native=True` only for the patient's own MRI/CT co-registration.
2. `analyze_case(target, run_name=None, overrides=None, parent_run=None, protocol=None, reason=None, spatial_sidecar=None, overwrite=False)`
   - Runs full-coverage QC, zero-phase SOS preparation, PyHFO detection (`STE`/`MNI`/`HIL`), cross-shaft synchrony stratification (`focal` vs `regional` vs `widespread_burst`), and optional ONNX scoring (`artifact`, `spike`, `ehfo`). Automatically reuses unchanged `qc`, `prepare`, and `detect` stages on branches.
   - Long recordings: restrict a run to a window with `overrides={"start_seconds": ..., "end_seconds": ...}`, or to several windows of ONE recording with `overrides={"segments": [{"start_seconds": ..., "end_seconds": ..., "label": ...}]}` or `overrides={"marker_segments": {"pattern": "sz|seizure", "before_seconds": 60, "after_seconds": 60}}`. Times are true recording time (gaps in EDF+D files are never bridged). `analysis_window_too_large` means: pick a shorter window or segments.
3. `query_evidence(target, mode="auto", run_a="baseline", run_b=None, recording=None, channel=None, readers=None, review_set=None, onset_seconds=None, measure="ripple", epoch_seconds=10, text=None)`
   - `mode`: `"auto"`, `"recording_summary"`, `"compare_runs"` (symmetric diff / cross-ref L7 side-by-side), `"compare_recordings"` (unpooled concordance), `"control_windows"`, `"overlay_concordance"`, `"cohort_summary"`, `"evidence_map"` (per-contact biomarkers, within-recording ranks, descriptive convergence for `run_a`), `"epileptogenicity"` (ictal EI for one recording from `onset_seconds` or a global seizure onset marker), or `"reader_agreement"` (latest independent reader ratings for one recording/run; optional `readers` names and a frozen `review_set`, defaulting to clinical and research readers), `"trends"` (per-channel band power / line length / RMS / HFO rate per epoch for one recording, choose `measure`; navigation only, not seizure detection), or `"timeline"` (all files of a case on one admission-relative clock with gaps, pieces and searchable markers; filter with `text`, e.g. `"sz"`).
4. `render_evidence_card(target, channel=None, recording=None, run_name="baseline", event_id="top_focal", center_seconds=None, window_seconds=0.6)`
   - Renders 3-panel Clinical Triad PNG (`"top_focal"`, `"top_burst"`, `"control"` with noise-floor RMS, explicit `ev_XXXX`), 2-panel 3D/Axial SEEG Spatial Figure (`"spatial"`), per-contact biomarker heatmap with within-recording percentiles (`"evidence_map"`), or ictal energy ratios / change detections / normalized EI (`"epileptogenicity"`).
5. `open_workbench(action="focus", case=None, recording=None, run_name=None, compare_run=None, view=None, channel=None, shaft=None, queue_mode=None, action_ids=None, agent_reply=None, outcome="resolved", since_seq=None, wait_timeout=120, trigger_only=True, claim=True, consumer="agent", start_seconds=None)`
   - With `action="focus"`, `recording` and `start_seconds` (true time), the open reader jumps to that moment, e.g. a timeline marker or a trend peak.
   - Read `pending_report_actions` with `action="status"` for questions from the waveform reader, admission timeline and MDT Case Sheet. Reader and timeline questions are available before analysis. Use the context saved with each question, since the live viewport can move. Fields include `case`, `source`, `role` and, when selected, `recording`, `recording_id`, `run_name`, `channel`, `start_seconds`, `end_seconds` and `marker`. Window and marker bounds are true seconds within that recording. A marker carries its label and bounds. A case-wide timeline question has no recording.
   - Resolve the question with `action="resolve_actions", case=..., action_ids=[...], agent_reply="..."`. If header identity masking hides the case slug, use the question's opaque `case_ref` as `case`. The same reference works with `status` and `wait_action`. The reply appears alongside the resolved question. Use `action="wait_action"` or CLI `watch-actions --claim` for Co-Review standby.
6. `record_judgment(case, recording=None, run_name="baseline", channel=None, event_id=None, verdict=None, clipped=None, note=None, clinical_question=None, clinical_overlay=None, author="agent", role="agent", operation_id=None, anatomy_labels=None)`
   - Records deduplicated clinician verdicts (`"confirm"`, `"artifact"`, `"uncertain"`), clips, questions, or source-attributed external SOZ/Resected clinical overlays. `anatomy_labels` replaces the case's anatomical annotations with an external source, `patient_native` boolean, and per-contact region labels (reuse `operation_id` on retry).
7. `export_or_protocol(action="export_case_sheet", case=None, recording=None, primary_run="baseline", comparison_run=None, clinical_question=None, protocol_name=None, description="", only_confirmed=False, exclude_widespread_bursts=True, targets=None, cohort_name=None, overrides=None, deidentify=False, pseudonym=None, review_set=None, sample_size=None, seed=None, readers=None, max_cards=6)`
   - Exports MDT Presurgical Case Discussion Sheet HTML (`"export_case_sheet"`), PowerPoint deck with up to `max_cards` Clinical Triad figures (`"export_mdt_slides"`), standard BIDS `*_events.tsv` (`"export_bids_events"`), annotated EDF+ plus annotation CSV / provenance JSON for EEG readers (`"export_edf_annotations"`), reusable Group Protocols (`"save_protocol"` / `"list_protocols"`), Multi-Patient Cohort batches (`"run_cohort"`), frozen review sets (`"create_review_set"` with `review_set` name, optional `sample_size`/`seed`), or agreement statistics (`"export_agreement_report"` with optional `review_set`/`readers`). Set `deidentify=True` (+ `pseudonym`) only when sharing exports outside the care team.

## 2. Non-Negotiable Neurophysiological & Clinical Guardrails

- **Separate Focal Candidates from Widespread Synchronous Bursts**: Simultaneous detections across `>=5` SEEG shafts within `±30 ms` are stratified as `widespread_burst` (common reference transients, arousal/EMG/DC shifts, or global pop) rather than focal epileptogenic HFOs. Always report **Focal (`<5 shafts`)** rankings alongside any widespread burst episodes.
- **Inspect Candidate-Free Control Windows**: Pair focal HFO Triad cards (`event_id="top_focal"`) with candidate-free background control windows (`event_id="control"` or `mode="control_windows"`) before concluding channel specificity.
- **Never Rank Zero-Event Channels or Pool Separate Recordings**: Only channels with `rate > 0` receive competition ranks (`#1, #2...`); `0`-event measured channels are `quiet_measured`, and `0`-coverage/AUX channels (`EKG`) are `unassessed`. Never average or pool event rates across separate recordings (`run-01` vs `run-02`).
- **Respect Sampling-Rate & Reference Physics**: Check Nyquist limits: display Fast Ripple filtering (`250–450 Hz`) requires `fs >= 577 Hz` (available at `1024 Hz` and `2000 Hz`, unavailable at `512–540 Hz`), whereas PyHFO ONNX `model_e` requires `[10, 500] Hz` spectrogram support (`fs >= 2000 Hz`; at `1024 Hz`, `artifact` and `spike` run while `ehfo` is honestly `unavailable` / `null`, never `0`). Never re-reference already-bipolar data unless explicit acquisition metadata permits it.
- **Role-Honest Verdicts**: Human clinician verdicts (`role="clinician"` / `"researcher"`), engineering rehearsal clicks (`role="engineering_rehearsal"`), and MCP agent assessments (`role="agent"`) are tracked separately; agent notes never inflate `clinician_confirmed` or Physician Review counts. Reader agreement excludes `agent` and `engineering_rehearsal` verdicts by default, and a blinded review session must never be unblinded by the agent.
- **Provenance Per Recording**: Determine origin strictly from each recording's saved provenance (`inputs/synthetic_seeg.edf` is synthetic CC0 test data; `inputs/HUP134` and `inputs/ZurichHFO` are real public CC0 clinical datasets). Never generalize the synthetic demo label to patient recordings.
- **Export Identity Defaults**: Exports (case sheet, MDT slides, BIDS events, annotated EDF+/CSV) keep patient identity by default for in-hospital use; use `deidentify=True` (with an optional `pseudonym`) only when sharing outside the care team. MCP responses never contain header-derived identity.
- **External Anatomy Labels Are External**: Anatomical labels come from an imported external table, never inferred from coordinates; always report them with their cited `source` and patient-native flag (`(non-patient-native)` otherwise).
- **Evidence Map & EI Honesty**: The evidence-map convergence count is descriptive, not a validated predictor, and IED candidates always require visual verification. Ictal EI comes only from an ictal recording with an explicit (`onset_seconds`) or marker-defined seizure onset, and is never pooled with interictal rates.
- **Clinical Humility**: Communicate concisely like a neurophysiology colleague (no legalistic boilerplate walls). Retain QC, coverage, reference, and spatial limitations, and frame all outputs as **Quantitative Neurophysiology Review Support — Not a Standalone Surgical Resection Boundary**.
