# Workbench display language

Use **EN / 中文** in the header to switch between English and Simplified Chinese. On the first visit, a browser language beginning with `zh` selects Simplified Chinese. Other browser languages select English. The workbench remembers an explicit choice in `localStorage` as `brainlens_language` for that browser and workbench address.

The switch updates the overview, waveform reader, 3D and report controls, keyboard help, review sets, agreement tables, evidence map and ictal EI results. Channel names, recording IDs, source attributions, units, user-entered notes and server messages retain their original text. Clinical exports, including the case sheet shown in the report tab, use canonical English. Readers can share a workspace while choosing their own display languages.

## Adding UI text

The offline catalog in `workbench/src/brainlens/assets/i18n.js` pairs each canonical English message with its Simplified Chinese translation. Use the English text as the key. Named placeholders let translations change the order of values. For example, `t("Page {page}/{total}", { page, total })` formats a reader page label. A missing translation falls back to English. Continue escaping recording and user data when constructing HTML.

In `index.html`, use `data-i18n` on the element containing the text. Put the text in its own span when it shares a control with an icon, input or keyboard hint. Use `data-i18n-title`, `data-i18n-placeholder` and `data-i18n-aria-label` for attributes. Give translated options explicit values so language changes preserve form and API values.

Run `workbench/tests/test_i18n.py` to check catalog coverage and placeholders. The language tests in `workbench/tests/test_browser_cdp.py` exercise live renders, reloads and the English case sheet in Chrome.
